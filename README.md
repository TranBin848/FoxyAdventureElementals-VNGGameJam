# FoxyAdventure: Elementals

FoxyAdventure: Elementals is a 2D fantasy action-adventure game developed with **Godot Engine** as a university course project organized by **VNG** and **University of Information Technology (UIT)**.

The game is built around the **Five-Element (Wu Xing) elemental system**, where each element counters another, creating a strategic combat experience that blends action and elemental decision-making.

---

## 🎮 Story

Foxy, the main character, once attempted to seize the power of the Five Elements for himself. However, this ambition backfired — his dark side was separated and later became one of the major bosses, while the good side of Foxy was blasted to the edge of the island and lost all memories.

The player begins the journey as a powerless Foxy, slowly rediscovering the elemental powers and uncovering the truth behind the corrupted version of himself.

---

## 🔥 Core Gameplay

The world of FoxyAdventure: Elementals is driven by elemental interactions:

- Every **enemy**, **boss**, and **environment** belongs to one of the Five Elements  
- Each element has strengths and weaknesses against others  
- Using the right element is the key to surviving difficult encounters  

Combat combines real-time action with elemental strategy, rewarding players who understand and exploit the elemental relationships.

## 📜 Skill System

The game features a deep and persistent skill system:

- Over **20 unique skills**  
- **4 skills per element**  
- Skills drop as **skill scrolls** from defeated enemies  
- Foxy uses a **magic staff** to cast learned skills  

Players can collect and store skill scrolls, then permanently unlock and upgrade them using the **Skill Tree**, which contains all skills available in the game. Once unlocked, skills remain available for future runs.

---

## 🧠 Skill Tree

The Skill Tree acts as a knowledge archive of all elemental abilities in the game.  
Players use collected scrolls to:

- Permanently unlock new skills  
- Upgrade existing skills  
- Customize their elemental playstyle  

This system allows long-term progression even when restarting or continuing the story.
